В задании №9 этот репозиторий содержит часть Schema.org и Open Graph. Сравнение производительности находится в [seo-performance](https://github.com/thesmol/seo-performance).

В каждой папке находится отдельное задание со всеми нужными файлами.

## Локальный запуск

```sh
npm ci
npm run dev
```

Откройте адрес, показанный Vite (обычно `http://127.0.0.1:5173/`). Для AJAX и XML используйте HTTP, а не `file://`.

Для сборки и проверки статической публикации:

```sh
npm run build
npm run preview
```

Для запуска нужен Node.js 20.19+ или 22.12+. При сборке файлы страницы копируются без изменений. Это сохраняет AMP-разметку и позволяет сравнивать исходные файлы в заданиях на производительность. Замеры лучше запускать через `preview`: в режиме `dev` Vite добавляет на страницу свой служебный скрипт.

### Задание №4

```text
Требуется полностью сверстать один из предложенных psd-макетов сайтов с использованием Flexible Box Layout Module. Верстка должна быть осуществлена независимыми блоками. Требуется разработать адаптивную версию. В коде необходимо наличие элементов базовой seo-оптимизации  (meta-теги keywords и description, семантические теги, заголовки title и h1, тег strong).

Результирующий код должен без ошибок проходить html- и css-валидацию на сайтах http://validator.w3.org/ и http://jigsaw.w3.org/css-validator/

Выгрузить страницу на внешний хостинг. Протестировать страницу с помощью инструмента Pagespeed Insights, проанализировать рекомендации и устранить возможные недостатки.

Приложение: addons/task4/...
```

### Задание №9

```text
Оценка необходимости применения фреймворков на простых задачах.
    Измерить время от начала загрузки страницы (!) до окончания отображения выводимых данных с использованием и без использования фреймворка jQuery на медленных соединениях/мобильных устройствах. Для оценки времени рекомендуется использовать метод performance.now(). Результаты оформить в виде графика в Excel.

    Для эмуляции медленных соединений в Google Chrome в режиме WebDeveloper(F12) в пункте Network использовать режим "Slow 3G". В браузере Firefox также есть подобные настройки.

    В качестве задачи использовать код решения задания №6 по обработке и выводу информации из xml- или json-данных. Целесообразно проводить измерения для файлов размером от 0.01-0.5МБ (от 10 до ~200 новостей).

    Исходные данные: Фреймворк jQuery(https://jquery.com/), пример подсчета времени от начала загрузки (https://yadi.sk/d/1ULKkFQtzSP1AA)

    Семантическая разметка страницы с помощью Schema.org и Open Graph
        Для сверстанного в задании №4 (контрольное) шаблона необходимо выделить 2-3 подходящих типа данных из поддерживаемых schema.org, и описать эту информацию с помощью соответствующих элементов микроразметки.
        Для сверстанного в задании №4 (контрольное) шаблона необходимо сформировать opengraph-описание страницы.

    Результат должен проходить проверку валидаторов микроразметки, например, https://webmaster.yandex.ru/tools/microtest/, https://developers.facebook.com/tools/debug/
```

### Задание №10

```text
Для сверстанного в задании №4 (контрольное) шаблона необходимо разработать amp-версию. Допускается упрощение верстки, однако страница должна смотреться аккуратно. Обязательные к использованию amp-теги: «amp-img» для изображений; «amp-sidebar» для основного меню.

    Результат должен проходить валидацию кода, например, с помощью https://validator.ampproject.org/

    Исходные данные: Документация AMP (https://www.ampproject.org/ru/), примеры AMP (https://ampbyexample.com/).
```

### Задание №11

```text
Для сверстанного в задании №4 (контрольное) шаблона подготовить xml- или json-структуру страницы, соответствующую методологии БЭМ. Провести доработку исходного html-кода для совместимости с основными принципами БЭМ.

    Исходные данные: Методология «Блок, Элемент, Модификатор» (БЭМ) (http://bem.info/).
```

### Задание №12

```text
Выбрать и установить любой БЭМ парсер, xml или json, в зависимости от структуры, полученной в задании №11. Подать на вход парсера эту структуру. На выходе требуется получить html-код исходной страницы шаблона.

Допускается использование online-инструментов, например, BEM XJST (https://bem.github.io/bem-xjst/) для json-данных. Допускается написание своего БЭМ парсера с использованием любых рассмотренных в курсе технологий (https://pastebin.com/eZmmwDt6).
```
